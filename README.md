# matchblox

A terminal console for people who run many AI coding agents at once. It shows
which agent is waiting for you, what loads the machine, the state of every git
checkout, and the one action that resolves each thing.

> **Status: in design.** The v0.1 design is in [design/0001-v0.1.md](design/0001-v0.1.md).
