# matchblox

**A tool for modern software builders.**

A terminal console for people who run many AI coding agents at once. It shows
which agent is waiting for you, what loads the machine, the state of every git
checkout, and the one action that resolves each thing. On the host, over SSH
from any terminal, or from your laptop.

*Dream big, build simple.*
