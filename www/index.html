Light an idea. Keep it burning.

Once, everyone carried a matchbox to light a fire wherever they went. matchblox is the one you carry to every terminal. It shows which coding agent works, which one waits for you, and what the machine needs, so the build never goes out.

Every agent in tmux

Start each agent in a tmux session. matchblox finds it, jumps to it with Enter, and answers it with a.

Claude Code, Codex and OpenCode also show how full their context is and which account they run under. Add any other agent by its command in agents.

Soon Start any agent from the console, without a tmux command.

matchblox stands on tmux: a server that keeps running, and clients that attach from any terminal. tmux, the engine →

Keep it burning while you sleep

Press n before you go. Each session that fills its context compacts itself and leaves one line on how to go on. In the morning you read it and carry on.

It never answers a question or a permission prompt, never says “continue”, and ends nothing. Claude Code for now. The stoker →

Waiting for you

Each agent that stopped, asks a question or asks for permission, oldest first. One key takes you to its pane.

Machine health, guarded actions

CPU, load, pressure, memory, temperature, and the busy loops nobody stopped. Each fix shows its exact command, and a destructive one waits for a typed y.

Any terminal, even a phone

On the host, or over SSH from any terminal app. Every key is on a phone's key bar.
